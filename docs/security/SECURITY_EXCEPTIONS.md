# Exceções de segurança

Nenhuma exceção está automaticamente aprovada.

## Modelo

| ID | Controle | Justificativa | Compensação | Responsável nominal | Aprovação | Expira em | Reavaliação |
|---|---|---|---|---|---|---|---|
| EX-000 | exemplo | motivo objetivo | controle temporário | pessoa | link/registro | AAAA-MM-DD | frequência |

Exceções sem prazo ou responsável são inválidas. P0 não pode ser aceito para go-live; P1 exige aprovação extraordinária e não é recomendado para dados reais.
