# Segurança de IA

Status: `NAO_APLICAVEL` no Checkpoint 07.

O VibeVenue não utiliza LLM, RAG, agentes, ferramentas autônomas, embeddings ou treinamento próprio. Nenhum dado de cliente deve ser enviado a provedor de IA sem nova análise de ameaça, inventário de fornecedor, base legal, isolamento de tenant, limites de custo, redaction, avaliação adversarial, human approval e kill switch.

A inclusão futura de IA reabre este controle e impede go-live até a fase específica ser concluída.
